# PXX · Nome do prompt

> **Módulo:** NN. Nome · **Quando usar:** situação concreta em que o pesquisador recorre a este prompt

**Objetivo:** uma frase com o resultado que o pesquisador obtém.

**Mecanismo epistemológico:** critério de rigor que a IA deve aplicar (framework, diretriz, princípio), com referência verificável.

## Prompt

```text
# PAPEL
Persona especializada, com o comportamento esperado (ex.: auditar, não elogiar).

# ENTRADA
- Campo 1: [EM MAIÚSCULAS ENTRE COLCHETES]
- Campo 2: [...]

# TAREFA
1. Passos numerados e verificáveis.
2. Tabelas de saída com colunas definidas.

# RESTRIÇÕES
- Não inventar referências, dados ou falas; marcar incertezas com [VERIFICAR].
- Pedir informação ausente em vez de presumir.

# ENCERRAMENTO
Ao final, inclua um bloco "RESUMO PARA O PRÓXIMO PROMPT" (até 8 linhas)
com as decisões e os resultados principais desta etapa, para que eu possa
colá-lo no próximo prompt do fluxo.
```
