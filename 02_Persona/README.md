# 02 Persona

Personas avaliadoras que simulam revisores, bancas, editores e orientadores, com bloqueio de condescendência.

| Código | Prompt | Objetivo |
| --- | --- | --- |
| P06 | [Revisor Ad-Hoc Q1](P06_revisor_ad_hoc_q1.md) | Simular a avaliação por pares cega (*blind peer review*) de periódicos de alto impacto. |
| P07 | [Advogado do Diabo](P07_advogado_do_diabo.md) | Testar os limites e a robustez lógica de uma tese/hipótese para bancas. |
| P08 | [Simulação de Banca de Qualificação](P08_banca_de_qualificacao.md) | Simular uma arguição com membros de perfis distintos (interno, externo, metodólogo) em formato interativo. |
| P09 | [Orientador Socrático](P09_orientador_socratico.md) | Conduzir o pesquisador por perguntas até que ele mesmo formule argumentos, decisões e soluções. |
| P10 | [Editor-Chefe (Desk Review)](P10_editor_chefe_desk_review.md) | Simular a triagem editorial inicial que decide se o manuscrito segue para revisão por pares ou recebe *desk rejection*. |
